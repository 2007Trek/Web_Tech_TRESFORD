# Tresford Mulilima — Computer Science Portfolio

A responsive personal portfolio for presenting academic background, selected software projects, technical interests and contact channels.

## Stack
- HTML5, CSS3 and vanilla JavaScript
- GitHub public REST API for live public profile and repository data
- Browser localStorage for persistent theme preference

## Features
- Responsive layout and accessible skip navigation
- Light/dark theme with saved preference
- Animated role headline with reduced-motion support
- Project, skills, academic journey and learning-priority sections
- Live public GitHub profile statistics and recently updated repositories
- Personal photo gallery
- Direct email, WhatsApp, Facebook, Instagram, TikTok and GitHub links
- Print-ready student CV at `cv.html` (use Print / Save as PDF)

## Run locally
Open `index.html` in a browser or use Visual Studio Code Live Server.

## Deployment
This is a static site and can be deployed using GitHub Pages, Render Static Sites or another static hosting provider. No build step is required.

## Honest functionality notes
- GitHub data uses the unauthenticated public API. GitHub rate limits may temporarily prevent the dashboard from loading; a direct profile link remains available.
- The email link opens the visitor's configured email application. There is no server-side contact form or message storage.
- No visitor counter is included because a reliable counter requires a persistent backend or trusted counter service.
- The portfolio assistant, generative AI chat, secure contact endpoint and server-backed visitor analytics are not represented as working features until their backend and privacy/security requirements are implemented.
- Certifications, awards and testimonials are omitted until verified evidence and permission are provided.
- Project links are only direct when the repository destination is known. Other project cards link to the public GitHub repository listing.

## CV
Open `cv.html` and select **Print / Save as PDF**. Review and complete the details requested in the CV note before submitting it for a job or internship application.
